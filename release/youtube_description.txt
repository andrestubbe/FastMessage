TITLE:
FastMessage: Universal Zero-Copy Messaging Engine for Telegram & WhatsApp in Java ⚡💬

DESCRIPTION:
Showcasing FastMessage, the ultra high-performance zero-copy universal messaging engine for the FastJava ecosystem. Watch FastMessage ingest, decode, and bridge Telegram Bot API updates and WhatsApp Cloud API webhooks with zero intermediate heap allocations, sub-microsecond latency, and bi-directional cross-platform transcoding.

FastMessage unites Telegram and WhatsApp into a canonical UniversalMessage format, featuring high-speed rule routing, token-bucket rate limiting, inline/reply interactive button builders, and a 120-column FastANSI telemetry display.

TECHNICAL HIGHLIGHTS:
- Zero-Copy Ingestion: Direct ByteSlice UTF-8 memory buffer indexing avoiding intermediate String/byte[] heap allocations.
- Telegram & WhatsApp Unified: Full bi-directional bridging with zero-alloc JSON parsers and serializers.
- Interactive Components: Telegram inline keyboards and WhatsApp interactive buttons, lists, and CTAs.
- High-Speed Routing: Predicate-based message bus with deduplication cache and per-user token-bucket rate limiting.
- FastANSI 120-Column Terminal HUD: Clean dark-gray framing with bold white values and live throughput telemetry.
